# kraftly-hacker-labb

Övningsrepo för **hackerlabbet** (vecka 7). Instruktionerna, poängen och regler finns i Canvas.

Det här är byråns *kampanjversion* av Kraftlys Mina sidor: samma portal, men med en egen snabbversion av inloggning som byrån byggde när "det riktiga API:t inte hann". Den fungerar. Den är också full av hål. Er uppgift är att hitta dem, bevisa dem, och sedan laga dem.

**Konton:** `anna.andersson@example.com` / `sommar2026` · `bo.bergstrom@example.com` / `bo1234` · (ett tredje finns)

## Kör

    npm install
    npm run api      # kampanj-API:t på http://localhost:4000
    npm run dev      # appen på http://localhost:5173
    npm run hacker   # "angriparens" sajt på http://127.0.0.1:6666 (en annan sajt än appen!)

Öppna appen i **Chrome** – labben bygger på hur Chrome hanterar cookies på localhost.

## Regler

Attackera bara det som körs på din egen dator. Allt här är påhittat. Det ni lär er är hur hålen ser ut i kod – så att ni känner igen dem i er egen portal.
